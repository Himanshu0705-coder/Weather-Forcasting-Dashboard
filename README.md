#  🌦️ Weather-Forcasting-Dashboard

An interactive **Weather Forecasting Dashboard** built using **Power BI**, designed to provide clear and insightful weather information through dynamic visualizations.

The dashboard fetches **real-time and forecast weather data through a Weather Forecasting API**, processes the data, and presents it in an easy-to-understand visual format.

### 🚀 Key Features

* 🌡️ Current temperature and weather conditions
* 📅 Multi-day weather forecasts
* 🌧️ Precipitation and rainfall information
* 💨 Wind speed and direction
* 💧 Humidity and other weather metrics
* 📊 Interactive charts and visualizations
* 🔄 API-based data fetching for updated weather information
* 📍 Location-based weather forecasting

### 🛠️ Technologies Used

* **Power BI** – Dashboard development and data visualization
* **Weather Forecasting API** – Real-time and forecast weather data
* **Power Query** – Data extraction, transformation, and cleaning
* **DAX** – Measures and calculations

### 🎯 Project Objective

The main objective of this project is to transform raw weather API data into an **interactive and visually appealing dashboard** that makes weather trends and forecasts easier to understand and analyze.
